# [FAA — fused add–add](@id faa128)

```@meta
CurrentModule = AIFloats
```

!!! warning "Unstable — not part of the public interface"
    Implementation detail. Names and behavior may change in any release without a
    deprecation. The supported surface is the [Reference](@ref reference).

`AIFloats.faa128` is a pure-Julia fused add–add for `Quadmath.Float128`, vendored from
SmallFloats.jl (provenance header in `src/carriers/faa128.jl`).

It is the companion to [`fma128`](@ref fma128), and exists for the same reason: the
draft's `FAA` operation is defined as a single correctly rounded `x + y + z`, so
evaluating it as two roundings would not implement it. A fused three-term addition with
a stated guarantee is what lets the operation take an exact path rather than the
enclosure ladder.
