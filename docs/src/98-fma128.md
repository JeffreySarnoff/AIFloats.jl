# [FMA — fused multiply–add](@id fma128)

```@meta
CurrentModule = AIFloats
```

!!! warning "Unstable — not part of the public interface"
    Implementation detail. Names and behavior may change in any release without a
    deprecation. The supported surface is the [Reference](@ref reference).

`AIFloats.fma128` is a pure-Julia fused multiply–add for `Quadmath.Float128`, vendored
from SmallFloats.jl (provenance header in `src/carriers/fma128.jl`).

It exists because `Float128` is a **carrier, not an oracle**: libquadmath's arithmetic
is never used to decide a rounding, so the exactness proofs that let Group A operations
skip the enclosure ladder need a fused operation carrying a guarantee of its own. A
computed product `p` is proved exact by `fma128(x, y, -p) == 0`, which holds only if the
fused operation is genuinely fused — with a rounded multiply followed by a subtraction,
the residual is not the residual. See [Algorithms](@ref alg-enclosure) for where those
proofs sit in the evaluation path.
