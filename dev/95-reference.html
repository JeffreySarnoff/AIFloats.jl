Reference

Every public name in AIFloats.jl: the exported bindings and those declared public.

The listing pages below are generated during the documentation build from Base.isexported and Base.ispublic, and the build fails if a public binding is neither documented nor listed as a reviewed exemption. The reference is therefore complete by construction, and holds nothing private.

Names you can call unqualified are exported; the rest are public and are reached as AIFloats.name.

The 504 generated format aliases are deliberately absent. Each says only that it is the format its own name spells out — Binary6p3ue is Binary(6, 3, UNSIGNED, EXTENDED) — so listing the 120 exported ones buried the entries that carry information. They keep their docstrings and still answer to ?Binary6p3ue; Concepts gives the naming scheme once and in full.
