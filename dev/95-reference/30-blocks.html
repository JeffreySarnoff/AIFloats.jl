Block containers

AIFloats.Block — Type
Block{B, S<:BinaryValue, E<:BinaryValue}

A P3109 block (s, (x₁ … x_B)): a scale datum of type S and B ≥ 1 element datums of type E (draft §5). isbits.

Block(Binary8p1uf(4.0), (Binary5p2se(3.0), Binary5p2se(0.5)))
Block(s, x1, x2, x3)          # varargs form
source
AIFloats.BlockVector — Type
BlockVector{B,S,E} <: AbstractVector{Block{B,S,E}}

Structure-of-arrays storage for blocks: scales::Vector{S} and elems::Matrix{E} (B × n, column-major, so each block's elements are one contiguous column). Build from a vector of blocks: BlockVector(blocks).

source
AIFloats.blockdecode — Function
blockdecode(b::Block) -> NTuple{B}

The values the block denotes: per lane ωMultiply(decode(s), decode(xᵢ)), exact on a carrier (Float64 when the product is exactly representable there, BigFloat otherwise). The draft's fold algebra applies: 0 · ∞ and NaN lanes are NaN. Not exported.

source
AIFloats.blockproject — Function
blockproject(FR, ρ, sr, Z; rng) -> Block

ωBlockProject (draft §5.1.2): each lane result in Z (a carrier value or an enclosure) divided by the result scale sr and projected into FR under ρ; the block returned carries sr. Not exported.

AIFloats.ConvertFromBlock — Function
ConvertFromBlock(FR, ρ, b::Block; rng) -> NTuple{B, BinaryValue}

Draft §5.2.1: decode the block and project each lane into FR — no scale division; the scale is folded into the values.

AIFloats.ConvertToBlock — Function
ConvertToBlock(FR, ρ, xs::NTuple{B, BinaryValue}, s::BinaryValue; rng) -> Block

Draft §5.2.2: the elements' values, block-projected against the supplied scale s into element format FR.

source
AIFloats.ConvertToBlockMaxAbsFinite — Function
ConvertToBlockMaxAbsFinite(FS, FR, ρs, ρ, xs::NTuple{B, BinaryValue}; rng) -> Block

Draft §5.2.3: the scale is reduce(ωMaximumFinite, [NaN, |x₁| …]) projected into FS under ρs; the elements are then block-projected against it into FR under ρ. All-NaN input gives a NaN scale (and NaN elements); infinities never set the scale but survive as ±Inf elements.

Block operations

AIFloats.BlockAbs — Function
BlockAbs(fr, ρ, b1, sr; rng) -> Block

Abs applied lanewise to 1 shared-scale block, with sr as the result scale.

Each operand block is (scale, elements); the lanes are decoded at scale * element, Abs is formed on the common carrier, and every lane is projected once into fr against sr (see blockproject). All operand blocks must have the same block size B; the result is a Block of that size.

When every operand scale and sr are one, the call reduces to B independent Abs calls — same answer, no scale arithmetic.

rng applies only under a stochastic ρ, and the lanes draw in index order from one stream.

Negate applied lanewise to 1 shared-scale block, with sr as the result scale.

Each operand block is (scale, elements); the lanes are decoded at scale * element, Negate is formed on the common carrier, and every lane is projected once into fr against sr (see blockproject). All operand blocks must have the same block size B; the result is a Block of that size.

When every operand scale and sr are one, the call reduces to B independent Negate calls — same answer, no scale arithmetic.

rng applies only under a stochastic ρ, and the lanes draw in index order from one stream.
