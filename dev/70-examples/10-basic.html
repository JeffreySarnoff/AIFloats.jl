Basic examples

These examples use the exported Binary8p4se alias: an eight-bit, four-bit precision, signed, extended format. Throughout the documentation F is a format, T a datum type, x a datum, c a code point, and ρ a projection.

Construct and inspect values

using AIFloats

F = Binary8p4se          # the format
T = BinaryValue(F)       # the datum type
x = F(1.5)
y = F(0.25)

(x, decode(x), codepoint(x), x isa T)
(1.5, 1.5, 0x44, true)

A datum stores a code point. decode returns its exact numeric value on the format's carrier; codepoint returns the stored encoding. formatof(x) recovers the format from a datum you were handed — there is no need for it when you already hold F.

Numbers and code points are different arguments

Every constructor argument is a number, Unsigned included. To name a raw code point, use fromcode:

using AIFloats

F = Binary8p4se
(fromcode(F, 0x45), F(0x45), F(69))
(1.625, 72.0, 72.0)

fromcode(F, 0x45) is the datum living at code point 0x45. F(0x45) is the number 69 projected into F — the same thing F(69) means. The two questions never collide, so F(codepoint(y)) can never silently reinterpret y.

An out-of-range code point is refused rather than truncated:

using AIFloats

F = Binary5p2se          # a 5-bit format: code points are 0x00:0x1f
try
    fromcode(F, 0xff)
catch err
    err
end
ArgumentError("code point 255 is outside 0:31 for Binary{5, 2, SIGNED, EXTENDED}; for the numeric VALUE 255 write Binary5p2se(255)")

Calculate with Julia syntax

Same-format values support Julia's ordinary numeric spelling. These methods use the task's DefaultProjection, initially RTE_SN.

using AIFloats

F = Binary8p4se
x, y = F(1.5), F(0.25)
@assert x + y === Add(x, y)          # each operator is one register call
(x + y, x * y, x / y, sqrt(x), exp(y))
(1.75, 0.375, 6.0, 1.25, 1.25)

The named register operations are available when the result format and projection should be visible at the call site:

using AIFloats

F = Binary8p4se
x, y = F(1.5), F(0.25)
(Add(F, RTE_SN, x, y), Multiply(F, RTZ_SF, x, y))
(1.75, 0.375)

See Operations for the full family: signatures, mixed operand formats, the correctness route each operation takes, and the refusals.

Convert values explicitly

Construction uses the task's default projection. Convert makes the format and projection explicit:

using AIFloats

F = Binary8p4se
value = 1.2
nearest = Convert(F, RTE_SN, value)
toward_zero = Convert(F, RTZ_SN, value)
(
    input = value,
    decoded = (decode(nearest), decode(toward_zero)),
    codes = (codepoint(nearest), codepoint(toward_zero)),
)
(input = 1.2, decoded = (1.25, 1.125), codes = (0x42, 0x41))

Convert between AIFloats formats explicitly as well:

using AIFloats

x = Binary8p4se(1.5)
Small = Binary5p2se
s = Convert(Small, RTE_SN, x)
(s, decode(s), Float64(s))
(1.5, 1.5, 1.5)

Classify and navigate

using AIFloats

F = Binary8p4se
x = F(1.5)
(Class(x), NextLessThan(x), NextGreaterThan(x), eps(x))
(ClassPosNormal, 1.375, 1.625, 0.125)

Special accessors make important endpoints easy to name:

using AIFloats

F = Binary8p4se
(MinPositiveOf(F), MinNormalOf(F), MaxFiniteOf(F))
(0.0009765625, 0.0078125, 224.0)
